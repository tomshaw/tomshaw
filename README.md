### 📚 Laravel Projects

#### ⚡ [Electric Grid](https://github.com/tomshaw/electricgrid)

Electric Grid is a Livewire data table package aimed at building rich, configurable grids for Laravel apps. It focuses on sortable and filterable columns, mass actions, exports, and theming, making it a solid choice for projects that need a full-featured table experience.

#### 🔗 [Google API](https://github.com/tomshaw/google-api)

Google API is a Laravel service client for Google OAuth 2.0 and Google APIs. It provides configuration for OAuth flows, token storage adapters, and example service adapters (like Calendar, Gmail, Drive, and Books) to simplify building Google-integrated Laravel apps.

#### 📦 [Laravel Dropbox](https://github.com/tomshaw/laravel-dropbox)

Laravel Dropbox is a Laravel client library for Dropbox API 2.0. It emphasizes configurable token storage, token refresh middleware, and a facade-based interface to make common Dropbox operations (auth, files, sharing, and user data) straightforward.

#### 👤 [Laravel Gravatar](https://github.com/tomshaw/laravel-gravatar)

Laravel Gravatar provides a zero-config Blade directive for generating Gravatar image URLs. It supports named parameters for size, default image styles, rating, and security, making avatar rendering easy in Laravel views.

#### 🖼️ [Mediable](https://github.com/tomshaw/mediable)

Mediable is a lightweight Laravel Livewire media manager for uploading and selecting files. It supports images, videos, and documents, offers optional image conversions, and includes events and configuration options for storage, validation, and integration.

#### 🛒 [ShopCart](https://github.com/tomshaw/shopcart)

ShopCart is a modern Laravel shopping cart library focused on simple item management with computed totals. It provides Cart and CartItem APIs for adding, updating, and removing items, with built-in tax rates, number formatting, and collection-based access.
